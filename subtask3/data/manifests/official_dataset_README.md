# FinNLP 2026 Subtask 3 — PolyFiQA

Files:

- `train.parquet`: 76 public labeled PolyFiQA examples supplied by the organizers.
- `test.parquet`: 76 hidden-answer participant examples with stable row IDs.
- `SOURCE_DATASET_CARD.md`: source PolyFiQA dataset documentation and citation.

`task_id` identifies a source financial-report document and repeats four times. The added `id` column is the unique submission key. Test answers remain in the private competition repository.
